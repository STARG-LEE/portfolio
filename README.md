# 이규성 포트폴리오

https://starg-lee.github.io/portfolio/

경영학에서 출발해 AI로 헬스케어와 바이오 문제를 푸는 데이터 연구자 이규성의 연구, 과제, 프로젝트를 정리한 사이트입니다.

## 구조

```
index.html          내용 전부(한 페이지, 자바스크립트 없음)
styles.css          디자인. 색·글꼴·간격 기준은 DESIGN.md
service-worker.js   2025년판 PWA 캐시를 지우고 스스로 해제하는 파일
DESIGN.md           디자인 결정 기준
assets/img/         사이트에 쓰는 이미지(논문·포스터 썸네일, 활동 사진, 공유 미리보기)
*.jpg, *.png, *.pdf 2025년판 원본 파일(예전 링크 유지를 위해 그대로 둠)
```

빌드 과정 없이 정적 파일 그대로 GitHub Pages(`main` 브랜치 루트)에 배포됩니다.

## 고치는 법
- 내용은 `index.html`에서 해당 섹션(`#research`, `#projects`, `#builds` 등)을 찾아 고칩니다.
- 이미지는 `assets/img/`에 WebP로 넣고 `width`·`height`를 적어 화면 흔들림을 막습니다.
- 확인되지 않은 수치나 투고 전 원고의 정확한 제목은 싣지 않습니다.
